PROJECT NOTES / HANDOFF

Designed to be
useful after the demo.

01 / PRODUCT

Animal-care MVP

Start with search, service filters, useful provider cards, provider details, business submission and corrections. Production listings need verification, moderation and timestamps before trust labels are shown.

02 / CONVERSION

Course journey

Explain the outcome first, show a concrete curriculum, then collect the minimum lead details. This prototype saves leads only in the browser. A live launch should send consented enquiries to a CRM and show a real confirmation message.

03 / SYSTEM

AI-assisted content

Use an LLM for research and slide drafts, a reusable Canva or Figma template for visual consistency, and optional n8n automation for brief intake and approvals. Keep final fact and brand review with the founder.

04 / BUILD

Suggested stack

Next.js or a lightweight static front end; Supabase for provider and lead data; a managed form/CRM; Canva templates for editable carousels; n8n when repeat volume justifies automation.
